    El reemplazo oficial se calcula como $\mathbf{\min(\text{recovery-equivalent score}, 60)}$ de forma independiente por unidad[cite: 14].

\section*{Reglas de Crédito Parcial[cite: 14]}
\begin{itemize}
    \setlength\itemsep{0.2em}
    \item \textbf{Modelo Correcto + Error Aritmético:} Conserve la mayor parte del crédito analítico[cite: 14].
    \item \textbf{Error Temprano Propagado:} Si un error se propaga pero la física posterior es coherente, no penalice repetidamente el mismo error[cite: 14].
    \item \textbf{Modelo Incorrecto + Aritmética Correcta:} Crédito analítico bajo (Ej. seguir asumiendo Zener en $5.1\,\text{V}$ si se calculó un $I_Z < 0$)[cite: 14].
    \item \textbf{Resultado sin Justificación:} Recibe crédito parcial si el ítem requería interpretación de la convención de salida[cite: 14].
\end{itemize}
