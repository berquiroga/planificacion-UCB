\begin{tcolorbox}[colback=yellow!10, colframe=black, title=\textbf{Convención de Evidencia y Reglas de Clasificación (Bloque A)} {[cite: 16]}, left=2mm, right=2mm, top=1mm, bottom=1mm]
    \scriptsize\raggedright
    \begin{itemize}
        \item \textbf{\texttt{CONFIRMADO}:} Existe una fuente identificable, fechada y relevante para la instalación local (placa autorizada, captura de sistema bajo supervisión, commit/archivo local verificado)[cite: 16].
        \item \textbf{\texttt{PENDIENTE}:} Todavía no se cuenta con evidencia local verificable. Si no hay acceso al controlador, se documenta el bloqueo institucional, el responsable de acceso y la solicitud formal[cite: 16].
        \item \textbf{\texttt{INCOMPATIBLE}:} Incompatibilidad demostrada mediante la contradicción directa entre un requisito técnico documentado y un dato local verificable. \textbf{El mero desconocimiento nunca se rotula \texttt{INCOMPATIBLE}}[cite: 16].
        \item \textbf{Separación de dos niveles:} \textit{«El README del candidato A exige la opción X»} puede estar \texttt{CONFIRMADO} como requisito del software, mientras que \textit{«El ABB de Tarija posee la opción X»} permanece \texttt{PENDIENTE} hasta comprobarlo en el equipo[cite: 16].
    \end{itemize}
\end{tcolorbox}
